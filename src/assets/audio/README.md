# Fire crackle

`fire-crackle.mp3` is the original user-provided upload `soundreality-fire-crackling-sound-499636.mp3` (79.536 seconds, stereo, 48 kHz). No re-encoding was applied.

The Web Audio mixer loads it on demand and plays one shared loop. Its gain is capped at 0.08 before master volume, multiplied by screen-centering and apparent-fire-size factors, with smoothed changes. Smoke alone makes no crackling sound. Pausing, menus, mute, and hidden tabs silence the ambience.
